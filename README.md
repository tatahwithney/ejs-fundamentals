# EJS Fundamentals

A Node.js and Express.js project for learning and practising EJS (Embedded JavaScript Templates) and server-side rendering.

## Features

- Express.js server
- EJS as the view engine
- Dynamic server time on the home page
- Static about page
- Dynamic users page
- EJS loops and expressions
- HTML navigation between views
